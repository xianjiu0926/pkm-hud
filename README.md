# pkm-hud

SillyTavern 宝可梦 HUD 脚本（单一文件 `pkm-hud.js`），文字/图片数据按需加载自配套数据仓库 [xianjiu0926/Pokemon](https://github.com/xianjiu0926/Pokemon)。

## 使用

将 `pkm-hud.js` 内容粘贴到角色卡的 Tavern Helper 脚本区域即可。
